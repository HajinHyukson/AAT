# Equity Module v0.1 Rights Redaction Results

Unknown rights block export. Restricted raw provider data is not exported. Licensed data is entitlement-locked. User-private data is blocked by default outside creator white-box mode. Marketplace draft is redacted and non-monetized.

Verified behaviors:

- Public-only package scenarios build.
- Restricted or unclear rights block export.
- Licensed provider data is entitlement-locked when connector entitlement is absent.
- User-private portfolio/document data is blocked in marketplace_draft and redacted outside creator-local white_box flows.
- marketplace_draft is redacted, non-monetized, and carries the non-advice boundary.

The rights matrix remains a registry seed. Legal/source-rights review is still required before production or marketplace distribution.
